# Glosario para clientes

## Cuando su sitio está disponible

Si el portal informa que el sitio está operativo, significa que su sitio está disponible. Si informa que está degradado, significa que el sitio funciona parcialmente pero puede estar lento o presentar fallas parciales. Si informa que está caído, significa que el sitio no está disponible en este momento y el equipo está trabajando en ello.

## Cuando aparece una falla crítica

Si aparece la información «Falla crítica: atención inmediata», se está describiendo un incidente P1. Esto significa que el sitio no funciona o que se están perdiendo ventas y que el caso recibe atención inmediata las 24 horas.

## Cuando se informa sobre disponibilidad

Si la disponibilidad está dentro del objetivo acordado, el portal muestra que el sitio se mantuvo disponible dentro del objetivo mensual. Si estuvo por debajo del objetivo, significa que el sitio estuvo disponible menos de lo acordado y el equipo explicará qué pasó y qué mejoras se realizaron.

## Cuando todavía no hay datos

Si el portal indica que todavía no hay datos del monitoreo de ese mes, significa que el sistema aún no cuenta con información suficiente sobre la disponibilidad del sitio durante el período.

## Cuando no hubo incidentes

Si se informa que no hubo fallas que afectaran el sitio durante el mes, significa que no hubo incidentes reportados o registrados que impactaran el servicio.

## Cuando no hubo solicitudes

Si se informa que no se abrió ninguna solicitud durante el mes, significa que no se registraron solicitudes de servicio o cambio durante ese período.

## Cuando hay una falla temporal

Un error temporal identificado por el sistema puede mostrarse como una falla temporal y un proceso de recuperación. No significa necesariamente que la causa esté resuelta; significa que el equipo ha iniciado las acciones correspondientes.

## Cuando se restaura una versión estable

Si se informa que se restauró una versión estable, significa que se volvió a una versión anterior que funciona para mantener la continuidad del sitio.

## Cuando el sitio presenta lentitud

Si se informa de lentitud elevada, significa que el sitio respondió más lento de lo esperado y el equipo inició una acción de mejora.

## Cuando se detiene una actualización por seguridad

Si una actualización fue detenida por controles de seguridad, significa que se encontró una actualización sensible, una vulnerabilidad o un elemento que impide confirmar el origen seguro de la actualización antes de publicarla.

## Cuando se publica una actualización

Si el portal indica que se publicó una actualización, significa que el cambio solicitado fue revisado y publicado en el sitio.

## Tiempo de recuperación

El tiempo de recuperación representa cuánto tardó el equipo en recuperar el sitio después de que comenzó el incidente.

## Solicitud

Una solicitud es un caso registrado para una atención, consulta, mantenimiento o cambio. El término técnico «ticket» se presenta al cliente como solicitud.
